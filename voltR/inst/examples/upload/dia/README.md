# Esempi DIA per voltR

Questi file sintetici mostrano il formato per importare cluster, indicatori
atomici e prestazioni indicatore nei workflow DIA-aware di `voltR`.

- `esempio_cluster_dia.csv`: cluster e pesi di livello superiore.
- `esempio_indicatori_dia.csv`: indicatori atomici con direzione, peso intra-cluster, fonte e stato validazione.
- `esempio_prestazioni_indicatori_dia.csv`: valori delle alternative rispetto agli indicatori.
